# jericbas.github.io ⚡

Personal website, developer journal, and open-source portfolio of **Jeric Bas**.

🌐 **Live site**: [https://jericbas.github.io](https://jericbas.github.io)

---

## 🛠️ Quickstart

Run locally using [Bun](https://bun.sh):

```bash
# Install dependencies
bun install

# Start local development server
bun run dev

# Build production static site
bun run build

# Preview production build locally
bun run preview
```
